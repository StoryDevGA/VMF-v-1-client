# Customer Workspace

Status: Draft local Help content for SS-032 and SS-036. Publication remains blocked until the StoryDevGA/VMF-v-1-client repository binding is connected and the published content is read back.

Customer Home gives you a bounded summary of the selected customer and tenant workspace. Advisor Recommendation, Attention required, and Recent activity are scoped to that context.

Use the Project Workspaces filter to choose:

- **Draft** — workspaces in the customer-facing draft lifecycle stage.
- **Published** — published workspaces.
- **All** — every available workspace in the selected customer and tenant context.

The selected filter is remembered while you move around Home and Project Workspaces, refresh, or re-enter the session. After signing out and back in, the last valid choice is restored for the same user and customer/tenant context. A different tenant or customer has its own preference. If a saved choice is invalid or unavailable, Home safely returns to Draft.

Select **Open** on a workspace to open its Execution Workspace overview for that selected revision. The overview carries the selected customer, tenant, workspace and revision into its bounded summaries. Use **Home** in the global header to return to Customer Home. For instructions on status, revision navigation, Advisor, the journey, capability cards and information popups, see [Execution Workspace](execution-workspace.md).

Changing or restoring the workspace filter does not change Advisor Recommendation or the five newest Recent activity items. Use **Why this recommendation** to see the recommendation context, **View all** for the Attention Centre, or **View all activity** for the Activity Centre.
