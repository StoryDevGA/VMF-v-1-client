# Intelligence Hub Sources

## Customer-supplied research reports

Open the report source and choose **Source details**, or open **Recorded text and Review** for an exact evidence item. **Customer-supplied research** identifies a customer-provided report rather than native Public Research. Inspect the supplier's recorded user ID, supply time, delivery method, original byte hash and Run/Attempt. A report retrieved from a supplied URL separately records that exact URL, retrieval time, response type and recorded source-access basis/attribution. The generic source type remains Uploaded document. In Source details, Supplied via distinguishes Public report URL from a file upload. Neither delivery method makes it independently researched company evidence. Tool, model/version, research method, supplier permission reference and declared citation URLs remain customer declarations; unknown details stay explicit. A declared link is not a separately captured source, verified citation or proof of its claims. Links are not automatically followed.

Choose **Inspect report original** to request the current audited original record. When that read matches the selected source and revision, **Download original report** retrieves the exact retained attachment. Its byte length and SHA256 must match the recorded original before a download is prepared. The file uses an original-ID filename with its supported extension and opens in your own document reader. No uploaded HTML is executed in the inspection. An unavailable read, missing audit or hash mismatch does not produce a substitute file; refresh and inspect the recorded Run outcome before continuing. Some connections may not expose the required download audit; the download stays unavailable there.

After original inspection, **Links found in retained report** shows separately detected URL-like text and supported embedded hyperlinks, with their locations. These come from the exact retained report bytes, not a search or a citation-page visit. They remain separate from manually declared URLs. Inspection covers bounded TXT text, DOCX main-document text/links, PPTX slide/linked-note text/links and PDF native text/link annotations. Other locations, images and scanned content may be missing. Repeated targets appear once at their first found location, and URL-like text can include punctuation.

Coverage is explicitly partial. No found links does not mean no bibliography; a limit or unavailable extraction does not invalidate an otherwise verified original download. Inspect the original for complete citations, qualifications and unknowns. Detected links create no additional sources or evidence, and are not independently verified support. Exact evidence excerpts and their spans refer to normalized extracted text, not PDF page numbers or original-file locations. All normal review and qualification decisions remain separate. Original access uses the existing workspace permissions and 30-day Development/Test policy, not a Production retention decision.

Sources is the canonical unique-source registry for the selected revision. A source can contribute many evidence objects; source totals and evidence totals are different counts.

## Search the complete revision

Search looks across source records and evidence, including records beyond the first page. Source matches and evidence matches are separate result streams. An evidence match opens its exact source and focuses that exact evidence object.

Source pagination is independent of the selected source's evidence pagination. Evidence contribution counts describe that source's actual evidence population, rather than the number of visible rows. Source processing state, domain and classification appear only when the governed read supplies them.

Matching sources describes the current search population. Whole-revision sources is the canonical unique-source count shared with Overview and Context, independent of search and pagination. Documents processed counts distinct current uploaded-document sources with verified successful acquisition receipts matching their current content. It does not count evidence objects, visible rows or Runs. A successful extraction with zero eligible evidence objects counts once. Legacy sources without verified receipt linkage are unknown; a receipt for changed content is stale. Neither is silently counted as processed.

## Inspect and review

The **Qualified evidence package** inspection uses the same source/evidence registry. It is not another public-research queue. Open a package preview or reopen the saved package, expand an evidence entry in its qualification ledger and choose **Open exact source and evidence** to inspect that precise source/evidence pair.

Each accepted package item retains publisher/locator, retrieval and currentness, exact excerpt and UTF-16 span, content/source hashes, certainty, scope, qualifications, permitted/prohibited interpretation, unknowns and derivation where recorded. **Not recorded** and explicit unknowns are information gaps; acceptance never fills them by inference. Coordinates refer to normalized extracted text, not original page coordinates.

The package Evidence Register and Validated Customer Baseline link to the same frozen membership and qualification ledger. Observations, patterns, hypotheses, contradictions and unknowns retain their supporting evidence links. The package preserves attribution and limitations; it does not approve stronger claims, change customer truth, lock the workspace or publish an output. Recorded packages can become historical after a later basis change and remain inspectable without being represented as current.

Select a source, inspect its evidence statement and provenance, then follow the exact evidence handoff to Review. Accepted, Rejected and Needs Review describe evidence decisions. Acceptance does not establish independent verification, confidence, quality resolution or snapshot sufficiency.

An evidence title is a display label. When no title is recorded, the heading says Evidence object. The current read does not supply governed evidence classifications or domain assignments, so these remain explicitly unavailable even when a title exists. Titles, acceptance and validation states do not substitute for those contracts.

The selected-source heading reports that source's complete recorded contribution count, separately from any exact focused evidence match. Use Browse all evidence from this source to inspect its independently paginated evidence while preserving the source, revision and search context. Back restores the exact focus. If the source and evidence read bases disagree, the contribution count and this handoff remain unavailable until refreshed.

Exact source and evidence identities are kept in the link so Back and reload can restore focus. If that pair is unavailable or wrong for the selected revision, the view explains the failure instead of selecting a different record.

Source and evidence reads must match the current selected revision version and session before record inspection or Review handoff. During a failed or refreshing read, previous records are withheld. Invalid or repeated query fields offer Reset Sources query; an old selection cannot navigate after the revision, session or read basis changes. Search and Retry source reads remain available for recovery within the current verified scope.

## Record an evidence qualification

Open **Recorded text and Review** for an exact evidence object. **Evidence qualification** records your scope, currentness, time, historical context, attribution, permitted statement and interpretation, prohibited interpretation and limitations. Leave a field blank for **Not recorded**. Words such as Unknown or Historical are kept as you wrote them; the application does not invent missing facts, confidence or authenticity.

Choose **Edit qualification**, then **Save qualifications**. The note is optional. **Cancel qualification edit** discards only the unsaved draft. Saving requires update permission and an editable revision. The saved record is reread before success is reported. **Recorded qualification history** lets you reopen an exact earlier record with its recorded author and time. A history read that fails is unavailable, not an empty history.

**Matches current source and evidence** describes whether the recorded binding still matches the material; it does not certify your currentness statement. A source or evidence change can make that binding stale. Earlier records remain inspectable. Qualification does not accept evidence, verify the source, map it to a section, admit it to a package or authorise generation.

If a save is unconfirmed, further saves are blocked. **Recover original request** reads the original request identity without sending another save. A missing or unavailable receipt remains unresolved. **Refresh qualification reads** refreshes the selected scope; closing an inspection does not undo a record that was committed.

The saved neutral qualification and its receipt remain separate from any specialised draft-placement qualification. A historical or stale record is not silently treated as current. Recorded extraction confidence is not a statement of certainty.

## Recorded capture and exact support

Source details shows a recorded capture receipt when it is supplied and consistent with the current read. Recorded text and Review opens the selected evidence object's supporting excerpt and provenance. Inspect the source identity, capture time, extraction method and any recorded Capture Run and Capture Attempt. A non-run capture can have no Run or Attempt recorded; do not infer another execution identity from that absence. Capture receipts and document-processing receipts describe different operations.

Original content hash identifies the recorded input version. For website captures, it is calculated from the complete decoded response text; it does not identify the original transferred bytes. Extracted-text hash identifies the normalized text used for the supporting excerpt. Its span uses UTF-16 code units with an exclusive end: [start, end) includes the start and stops before the end. These coordinates are not original HTML positions, PDF pages or original-file locations. The exact recorded excerpt, excerpt hash and source binding keep support attached to its own source, even when another source contains the same words.

Where separately retained for a new supported input, original bytes have their own byte hash and retention-policy binding. That byte hash is distinct from the website capture hash and normalized-text hash above. A missing historical original remains unavailable; it is not reconstructed from an excerpt. This inspection does not promise an original-file download or a Production retention policy.

Recorded capture and support do not establish source authenticity, independent verification, evidence acceptance or frozen membership. Source assertions remain qualified statements awaiting their separate review decisions. If a receipt or supporting span is missing, stale or inconsistent with the selected source and revision, inspection explains that it is unavailable; it does not invent a location or substitute another source. A changed or unavailable read closes the previous inspection rather than keeping old details current.

## Read separately retained original material

Select the exact source, open Source details, then choose Read retained material when offered. The reader shows the full retained extracted text, source binding and licence attribution for a supported original. Use the supporting evidence excerpt and its recorded span to check what the source actually says. A source assertion is not independent verification, and readable material remains subject to a separate Review decision.

Retention and access are checked separately from the capture result. Research can be saved while original retention remains unconfirmed; inspect the recorded outcome before attempting anything else. If original material is unavailable, preserve that result rather than substituting a snippet or another source. Normal original reads are audited. The approved Development/Test policy is 30 days; that does not establish a Production retention policy or prove that historical material has been physically deleted.

Public-search discoveries remain in the recorded research Run. Their URLs and snippets are discovery metadata; they are not additional original sources or evidence items in this registry. Only separately captured and saved material contributes original evidence. Open the recorded Run from Context to inspect its discoveries, then return here for its saved sources.

For a supported News capture, Source details and the exact evidence inspection in Review show Recorded News provenance. Inspect its article title, recorded publisher and author, publisher publication time, retrieval time, exact URL and interpretation limits. Those values come from the captured page's NewsArticle metadata. Publication and authorship are publisher assertions; a public or official publisher does not establish independent reporting, a verified identity match or currentness. Missing author or publication time remains Not recorded. The research Run separately records NEWS and the source-provenance hash; the underlying HTML storage remains a website original.

## Partial, stale and unavailable reads

A bounded read can be partial or capped. An unknown total is unavailable, not zero. Refresh the selected scope when currency is uncertain. Do not treat an empty visible page as proof that the whole revision has no evidence.

Source population and processing proof can have different completeness. A complete source count can remain available while Documents processed is unavailable, qualified by verified, unknown and stale document counts. During loading, after a failed refresh or when the revision basis changes, the summary hides its previous values. Use Retry source reads to reread the exact selected scope. A processing-proof limit is explained separately from a source-population limit; neither establishes acceptance, quality resolution or readiness.

Acquisition belongs to [Context](intelligence-hub-context.md). Findings are resolved in [Intelligence Quality](intelligence-quality.md); outstanding evidence decisions belong in [Review](intelligence-hub-review.md).


A combined research release can retain separately nominated Website pages and one explicitly permitted News article. Their originals and qualifications remain source-specific. Public-search snippets and excluded search links remain discovery metadata in the Run history; they are not original evidence or additional capture permission. A recorded exclusion does not authorize visiting or capturing that link.


LinkedIn, X/Instagram and Reviews capture are currently unavailable; see the category explanations in [Context](intelligence-hub-context.md). Selecting them creates no category originals. A search result that mentions one of these services is still discovery metadata and does not establish a working category connection, licence or permission to capture its content.


For a supported GitHub capture, Source details and the evidence inspection in Review show Recorded GitHub provenance. Inspect the repository, root README file, requested immutable commit, canonical file URL, actual API request URL and retrieval time. The separately retained material is GitHub’s API HTML rendering of the README, not raw Markdown file bytes or independent Git-object verification. The pinned request does not establish the latest repository state, company ownership, adoption, security or customer outcomes. Publication time remains Not recorded. Read retained material for the captured text and licence attribution; every evidence item still requires its separate human Review decision.

For a supported Industry capture, Source details and the evidence inspection in Review show **Recorded Industry provenance**. Inspect the exact GOV.UK statistical publication, recorded publisher, publication time, content identity and nominated period and caveat quotes. These quotes occur in the captured text but do not establish that every measure uses one period. Read statistical uncertainty, tables and footnotes in context. The retained original is the published HTML; linked charts and downloads are not fetched. Read retained material to inspect the text and licence attribution. This is industry context, not facts about the target company or independently verified statistics. Evidence still needs its own human decision.
